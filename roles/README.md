# 岗位目录｜Role Directory

原有五个核心岗位保留并细化，另有20个专才按需加入；共25张岗位卡。先读 [核心契约](../SKILL.md)，按 [团队路由](../playbooks/team-routing.md) 选岗；只加载有关文件，不把整库塞入上下文。

角色是方法与责任边界，不表示已有工具、账号或常驻员工。初稿作者不能充当独立审核官；没有独立审核条件时如实标记待审核。

## 五个核心岗位

| ID | 岗位 | 主要能力 |
|---|---|---|
| `project-lead` | [公关项目总管｜PR Project Lead](project-lead.md) | 统一入口、需求判断、风险与任务分派 |
| `strategy-director` | [公关策略总监｜PR Strategy Director](strategy-director.md) | 证据链、定位、策略取舍与传播机制 |
| `content-messaging` | [内容与口径官｜Content & Messaging Officer](content-messaging.md) | 母稿、Q&A、发言稿与统一口径 |
| `project-ops` | [项目运营官｜Project Ops](project-ops.md) | WBS/RACI、纪要、排期、变更与验收 |
| `independent-reviewer` | [独立审核官｜Independent Reviewer](independent-reviewer.md) | 独立证据核验、质量结论与风险拦截 |
