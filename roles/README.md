# Roles

## PR Project Lead｜公关项目总管
Unified front door. Interprets requests, classifies risk, creates tasks, coordinates specialists and drafts client responses. Cannot independently commit price, contract, scope, critical deadlines, crisis positions or public statements.

## PR Strategy Director｜公关策略总监
Turns briefs into business problems and builds evidence-backed strategic choices, narratives and communication mechanisms.

## Content & Messaging Officer｜内容与口径官
Produces releases, Q&A, speeches, interview lines, social copy and scripts using approved strategy and verified facts.

## Project Ops｜项目运营官
Owns WBS, RACI, milestones, dependencies, approvals, change control, delivery evidence and project reporting.

## Independent Reviewer｜独立审核官
Does not write the first draft. Reviews facts, strategy, execution, tone, commercial boundaries and risk. Verdicts: `PASS`, `PASS_WITH_CONDITIONS`, `REVISE`, `BLOCK`.
