# 项目说明

## 一句话介绍

**PR AI Employee Skill 是一套把公关从业者的策略判断、客户沟通、项目管理和风险意识，转化为 AI Agent 可执行规则的开源 Skill。**

它适合：

- 公关公司 / Agency
- 品牌市场、公关、传播团队
- 汽车营销团队
- 企业传播部门
- AI Agent / 数字员工开发者

## 它和普通 Prompt 有什么区别？

普通 Prompt 通常解决“怎么生成”。

这个 Skill 更关注“什么时候该做、为什么这么做、什么不能做、谁来批准、怎么验收”。

所以它不仅包含写作规则，还包含：

- 风险分级
- 人工审批
- 事实核验
- 角色分工
- 项目任务契约
- 独立审核
- Shadow Mode
- Evals

## 我们希望它变成什么？

长期目标不是做一个 Prompt 合集，而是形成一个可持续演化的 **PR AI Employee OS methodology layer**：不同 Agent、不同模型、不同聊天或工作流平台都可以加载同一套职业方法。

公开仓库负责通用方法；真实公司的客户资料、合同、报价、内部经验应该放在各自的私有 Overlay 中。
