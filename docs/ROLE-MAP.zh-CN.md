# AI 公关岗位图

现有5个核心岗位负责总管、策略、口径、项目运营与独立审核；20个专才按任务加入。

唯一完整名单见 [岗位目录](../roles/README.md)，运行环境映射见 [registry.json](../roles/registry.json)。

```text
客户请求 → 公关项目总管（统一入口）
                 ↓
     策略总监 / 内容与口径官 / 项目运营官
                 ↓
     按需专才（研究、平台、媒体、视觉、数据、商务）
                 ↓
           独立审核官（非初稿作者）
                 ↓
      授权负责人审批 → 获批范围内交付
```

具体依赖和单Agent降级方式见 [团队路由](../playbooks/team-routing.md)。角色数量不意味着并发启动数量或自动执行授权。
