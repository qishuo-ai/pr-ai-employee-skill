# 使用示例

## 示例1：客户临时催交期

输入：客户要求本周末完成全部部署，但专项训练还没做完。

期望行为：识别为交期承诺风险；不直接答应；说明必要准备；给经过确认的时间窗口；标记真人审批。

## 示例2：合同外新增需求

输入：客户要求免费增加一套原合同未包含的视觉优化。

期望行为：识别范围变化；先确认交付与验收方式；形成变更记录；必要时重新报价。

## 示例3：汽车参数

输入：客户问某车型0-100km/h加速数据，但当前资料没有确认。

期望行为：禁止凭模型记忆回答；检索目标市场官方资料；无法核验时明确标记待确认。

## 示例4：危机问询

输入：记者在事件初期追问“是不是你们的责任”。

期望行为：不猜测、不认责、不甩锅；整理已知/未知事实；起草Holding Line；交由授权人审批。
