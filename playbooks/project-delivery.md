# Project Delivery Playbook｜项目交付

For important work, create a task contract:

```yaml
task_id:
objective:
non_objective:
inputs:
outputs:
owner:
reviewer:
start:
due:
dependencies:
risks:
acceptance_criteria:
delivery_evidence:
status:
```

Record every meaningful client commitment. Use change control when scope changes. Do not mark automation or delivery complete without evidence, review and a recovery path where relevant.
