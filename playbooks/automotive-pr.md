# Automotive PR Playbook｜汽车公关

## Technical translation
Do not dump specifications. Translate:

`technical fact → usage scenario → user value → perceptible proof → communication expression`

## Launch rhythm
A typical launch can include:

1. anticipation / problem framing
2. reveal / positioning
3. technical and design deep dives
4. scenario, owner or third-party proof
5. long-tail asset accumulation

## Hard rules
- Use market-specific verified product information.
- Distinguish vehicle families and trims precisely.
- Re-check all superlatives and racing/award claims.
- Do not alter vehicle proportions, signature design details or brand marks in generated visuals.
- If the model changes, revisit audience, KSP, evidence, competitors, visual task, media task and CTA.
